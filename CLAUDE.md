# Portail Médiathèque Conviviale

## Project Overview

Web portal project for a community media library (médiathèque). Built using the BMAD (Business-to-Mvp-AI-Development) methodology for AI-assisted development.

## BMAD Configuration

- **BMAD version:** 6.2.2
- **Output folder:** `_bmad-output/`
- **Communication language:** English
- **Document output language:** English

### Key BMAD Paths

- Core config: `_bmad/core/config.yaml`
- BMM config: `_bmad/bmm/config.yaml`
- Planning artifacts: see BMM config
- Implementation artifacts: see BMM config

## Development Workflow

This project follows the BMAD methodology:

1. **Analysis** — Product brief, domain/market research, PRD
2. **Plan** — Architecture, UX design, epics & stories
3. **Workflows** — Sprint planning, story execution
4. **Implementation** — Dev stories, code review, QA

Use the appropriate BMAD skill (`/bmad-*`) for each phase.

## Conventions

- All output documents go in `_bmad-output/`
- Story files go in `_bmad-output/stories/`
- Do not commit `_bmad-output/` artifacts unless explicitly requested
